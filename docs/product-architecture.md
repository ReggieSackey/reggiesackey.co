# Profession-neutral job analysis

The system does not assume a target profession. It interprets what an organization is trying to accomplish, identifies which demonstrated candidate capabilities could create value toward that outcome, and surfaces material constraints honestly. Job titles and technology keywords are evidence about the work, not the ontology of the candidate. The system should discover non-obvious fit without manufacturing fit.

Canonical case studies and profile sections remain the factual source. The reviewed capability registry interprets demonstrated patterns of action. A job-specific success profile describes the employer's mission, concrete work, success drivers, and conservative hard constraints. Application code combines those layers into value-oriented themes and owns requirement coverage, fit, material constraints, and citation identities; the model writes only the short narrative for that fixed plan.
